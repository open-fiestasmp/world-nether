# fiesta nether

Raw `world_nether` save from FiestaSMP (`fiestamc.neocities.org`), saved on 2026-11-21. It's the Nether dimension; the Overworld and End are in the other repos.

## grab the files

Open [Releases](https://github.com/open-fiestasmp/world-nether/releases), pick `snapshot-2026-11-21`, then download **Source code (zip)** and extract it. The green **Code → Download ZIP** link gets the latest branch instead.

## use it

**Single-player:** use the Nether data with the matching Overworld save and Minecraft version. Back up your save first; dimension folders are laid out differently across versions.

**Paper server:** stop it and back up its worlds first. Rename this extracted folder to `world_nether`, keeping its files as they are. Use `world` and `world-the-end` for the other two folders. Don't copy into a running world.
